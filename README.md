# ShipForm для Windows

[Скачать последнюю версию](https://github.com/yarch3s/ShipForm_Releases/releases/latest) · [Все версии](https://github.com/yarch3s/ShipForm_Releases/releases) · [Инструкция со скриншотами](ShipForm-Guide.pdf)

В разделе **Assets** скачайте `ShipForm.exe`. Начиная с ShipForm 1.0.2, приложение при запуске проверяет наличие нового выпуска и предлагает его установить. Контрольная сумма доступна в `ShipForm.exe.sha256`.
