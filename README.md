# ShipForm

ShipForm собирает ФУД в Excel из упаковочных листов, спецификаций закупки и спецификаций продажи. Программа работает на вашем компьютере: документы никуда не отправляются, в интернет она обращается только за обновлениями.

## Скачать и проверить

1. Откройте [последний выпуск](https://github.com/yarch3s/ShipForm_Releases/releases/latest) и скачайте `ShipForm.exe` и `ShipForm.exe.sha256`.
2. Сверьте контрольную сумму. Откройте PowerShell в папке со скачанными файлами и выполните:

   ```powershell
   (Get-FileHash .\ShipForm.exe -Algorithm SHA256).Hash.ToLower()
   Get-Content .\ShipForm.exe.sha256
   ```

   Первая строка должна совпасть с 64 символами в начале второй. Если не совпала, не запускайте файл и скачайте его заново.
3. Создайте папку на локальном диске, например `C:\ShipForm`, положите в неё `ShipForm.exe` и запустите. Установка не нужна. Не кладите программу в папки, которые синхронизирует OneDrive (на многих компьютерах это «Рабочий стол» и «Документы»), и в сетевые папки: оттуда обновление не установится.

Файл не подписан цифровой подписью, поэтому при первом запуске Windows может показать предупреждение SmartScreen. Если контрольная сумма совпала, нажмите «Подробнее» и «Выполнить в любом случае».

## Обновления

ShipForm 1.0.2 и новее при запуске проверяет, есть ли здесь новый выпуск, и предлагает установить его. Программа скачивает файл, сверяет контрольную сумму, заменяет себя и перезапускается. Перед установкой сохраните текущий ФУД.

В версиях 1.0.0 и 1.0.1 обновления внутри программы нет. Скачайте новый `ShipForm.exe` по ссылке выше и замените им старый файл.

Если обновление не установилось, замените файл вручную так же. ShipForm 1.1.0 и новее при этом называет причину и показывает кнопку «Страница выпуска», версии 1.0.2-1.0.4 сообщают только, что обновление не завершилось.

## Лицензии

Программа включает xlrd; This product includes software developed by David Giffin <david@giffin.org>.

Полный перечень лицензий сторонних компонентов показывает сама программа: ссылка «Лицензии компонентов» внизу окна и в меню «⋯» в верхней строке окна.

## Требования

- Windows 10 или Windows 11, 64-разрядная.
- Microsoft Edge, он входит в Windows. Без него программа откроется в браузере по умолчанию.
- Для просмотра готового ФУД нужна программа для файлов XLSX, например Excel.
- Для автообновления папка программы должна быть на локальном диске, доступна для записи и не синхронизироваться с OneDrive.
- Интернет нужен только для проверки и загрузки обновлений.

В этом репозитории лежат только готовая программа в разделе выпусков, это описание и инструкция.
